# Form result contact filters

The Form results screen now has two quick filters: **With contact** and
**Anonymous**. They classify submissions using the existing `lead_id` value.

Before this shortcut, reviewing one category meant using the contact ID column
filter and checking the returned rows. Open **Forms**, open a form's results,
then open the filter control and choose the needed view. The filter is read-only
and can be cleared with the normal reset control; it does not change a
submission or a contact.
