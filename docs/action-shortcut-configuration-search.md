# Configuration tab search

The Configuration page now has a `Find a setting` search field above its tabs.
Typing a setting name or a visible part of its help text filters the tabs and
opens the first matching tab. The search is local to the page: it does not
submit the form, change a value, or save configuration.

Before this change, a person had to open Configuration, inspect several tabs,
and search each long tab manually. With the search, the comparable path is to
open Configuration and type the setting to reveal its tab, while the normal
tabs remain available when the search is empty.
