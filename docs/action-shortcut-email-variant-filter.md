# Email variant filter

The Email list now offers a `Variants` quick filter. Selecting it applies
`is:variant` immediately and shows only Emails that have a parent variant.

The filter is read-only. It does not change, publish, clone, send, or delete
Emails. Use the existing Reset filter action to return to the full list.

Before this change, reviewing variants required opening Quick filters,
remembering or typing `is:variant`, applying the filter, and then checking the
results. The visible filter reduces that to opening Quick filters and choosing
`Variants`.
