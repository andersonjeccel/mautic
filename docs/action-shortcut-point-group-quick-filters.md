# Point Group quick filters

The Point Groups list now offers quick filters for active, inactive,
uncategorized and user-owned groups.

Before this change, reviewing one of these views meant opening Point Groups,
reading the rows, and checking each group's status, category or owner. The
new flow is to open Point Groups and choose the needed quick filter; the
selection applies immediately. The filter only changes the list view; it does
not edit, publish, categorize or delete a group. Reset restores the full list.
