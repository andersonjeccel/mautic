# Action shortcuts

## Repeat the last campaign event type

When building a campaign, choose an event group once (Action, Decision, or
Condition). When another connection allows that same group, the event panel
opens the existing picker for it and identifies the reused type. The panel
also shows **Repeat last type** when the user returns to the group choices.
The user still chooses the specific event, and **Back to the event selection
panel** remains available to change groups.

The shortcut is limited to the current builder page and does not create or
change a campaign until the normal event form is completed and saved.
