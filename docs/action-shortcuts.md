# Action shortcuts

## Dynamic content publication

For 10 dynamic content items, the previous flow required opening each item, changing its publication state, saving, and returning to the list: 40 steps. The list did not offer one clear decision for several items.

The new flow is: select the items, open Options, choose Publish or Unpublish, and confirm: 4 steps. The inverse action provides a clear way to undo the change, while the confirmation explains that availability for use will change.
