# Action shortcuts

## Webhooks: publish or unpublish selected items

Before: each webhook had to be opened, changed, saved, and the list revisited.
For 10 webhooks this is 40 steps. Now select the webhooks, open Options, choose
Publish or Unpublish, and confirm: 4 steps, a 90% reduction. The confirmation
keeps the consequence visible because the action controls requests sent to
external systems, and the inverse action provides a clear way to undo it.
