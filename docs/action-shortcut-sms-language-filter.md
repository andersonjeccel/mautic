# SMS language quick filter

The SMS list now includes a `Portuguese` quick filter. It applies the existing
`lang:pt` search command immediately, so it only changes the visible list and
does not edit, send, publish, or delete any text message.

Before this change, reviewing Portuguese SMS messages required opening the
quick-filter menu, remembering or typing `lang:pt`, applying the search, and
waiting for the list. Now the same review starts by choosing `Portuguese`; the
search remains visible and can be cleared with the existing Reset control.
