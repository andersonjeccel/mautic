# Role permission search

The Permissions tab in a role editor now includes a local search field. Type an
area or action, such as `campaign` or `publish`, to show matching permission
groups and rows. The filter only changes what is visible: selected checkboxes,
permission ratios, and the save buttons keep their existing behavior.

Before this change, reviewing one permission meant opening the Permissions tab,
finding the bundle in the long list, and scanning its rows. With the search,
the comparable flow is opening Permissions, typing the permission term, and
reviewing the matching checkbox without changing the role automatically.
