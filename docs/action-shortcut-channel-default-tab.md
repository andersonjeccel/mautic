# Channel editor default tab

The Marketing Message editor now opens the first channel with a validation error, then the first enabled channel, and finally the first available channel. All channel tabs remain visible and selectable.

This keeps the existing form permissions, validation and save flow unchanged. The default only helps the person start reviewing the channel that needs attention or is already in use.

## Verification

- Open a Marketing Message with more than one configured channel.
- Confirm that a channel with an error is opened first; otherwise, confirm that the first enabled channel is open.
- Select another channel and confirm it remains available for manual review.
