# Clear Dynamic Content filters

Dynamic Content builders can now remove all selected filters at once while editing. The button appears only when filters exist and asks for confirmation before changing the unsaved form.

Before this change, restarting a filter set meant removing each condition with its own trash button. With three filters, that took three repeated removals. The new flow is: click **Clear filters**, confirm, and continue with an empty filter set.

The action changes only the current form. It does not save, publish, delete, or affect an existing Dynamic Content item until the user submits the form.
