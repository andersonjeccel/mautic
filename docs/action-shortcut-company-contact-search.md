# Busca de contatos dentro da empresa

No detalhe de uma empresa, o painel de contatos agora tem uma busca própria.
Digite o nome, email ou outro termo aceito pela busca de contatos para atualizar
somente os contatos associados àquela empresa. A busca usa a mesma regra textual
da lista geral de contatos, mantém a ordenação e a paginação e pode ser limpa
para mostrar novamente todos os contatos.

Antes, era necessário sair do detalhe da empresa, abrir a lista geral de
contatos, pesquisar e voltar para conferir o resultado. Agora, a pesquisa é
feita diretamente no painel relacionado, sem alterar contatos ou permissões.
