# Report schedule shortcut

On a report detail page, the **Schedule** action opens the existing report editor directly on its Schedule tab. It does not save changes; the person still reviews the recipients, frequency, and preview before using the normal form action.

Before this shortcut, adjusting a report schedule required opening **Edit**, finding the **Schedule** tab, and then reviewing the settings. The contextual action removes that repeated navigation while keeping the scheduling decision and save action visible.

To verify it locally:

1. Open a report detail page.
2. Choose **Schedule** in the page actions.
3. Confirm that the editor opens on the **Schedule** tab with the existing preview.
