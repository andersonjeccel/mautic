# Page variant preview shortcut

## What changed

The variants shown on a Page detail screen now include a preview icon. It opens
that exact variant in a new browser tab using the existing Page preview route.

The shortcut is available only when the variant list is shown to a user who can
already view the Page. It does not save, publish, edit, or change the variant.

## Before and after

Before, reviewing a variant meant opening the variant, finding the Preview URL
card, choosing the variant again, and opening the generated URL. The detail page
now offers Preview directly in the variant row, so the review starts with one
click and keeps the current detail page open.

## How to verify

1. Open a Page that has at least one A/B variant.
2. In the Variants panel, select the preview icon on a variant row.
3. Confirm that a new tab opens the selected variant and the original detail
   page remains open.
