# Asset details stay open after filtering

On an asset detail page, applying a new download period now keeps the Details section open. The URL, file name, storage path and other metadata remain visible while the chart uses the selected period.

Before this change, applying the period reloaded the page and collapsed Details. The user had to open it again to compare the chart period with the asset metadata.

## Test

1. Open an asset detail page.
2. Open Details and choose another period for the download chart.
3. Confirm that the chart updates and Details remains open.
