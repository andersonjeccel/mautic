# Aba de filtros após erro no Dynamic Content

Quando o salvamento de um Dynamic Content falha porque os filtros estão
incompletos, o editor agora abre diretamente a aba Filters. A aba Details
continua sendo a inicial quando não há erro de filtro.

Antes, a pessoa via o aviso na aba Filters, mas precisava clicar nela para
encontrar o campo que precisava corrigir. A mudança só altera o contexto visual
após a validação; nenhum conteúdo é salvo automaticamente e os dados digitados
continuam no formulário.
