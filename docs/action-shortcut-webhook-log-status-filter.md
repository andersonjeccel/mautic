# Webhook response status filter

The Webhook detail page now filters its existing response log by successful or
error HTTP responses. The filter is local to the page, does not change or
remove logs, and can be reset to show all responses.

To verify it, open a Webhook with at least one 2xx response and one non-2xx
response, choose `Errors` or `Successful responses`, and then choose `All
responses` to restore the full log.
