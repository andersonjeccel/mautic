# Inline page preview

Page details now show the preview inside the existing preview panel. The translation, variant, and contact selectors continue to update the preview URL and the page displayed in the frame. The existing link still opens the same preview in a new tab.

This keeps review in one Mautic screen: choose a preview option, inspect the result, and change the option without switching browser tabs. The preview remains read-only and does not publish or save the page.
