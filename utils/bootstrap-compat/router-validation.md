# Bootstrap input router validation

The production bridge is generated byte-for-byte from `adapter/adapter.js`.
It forwards jQuery plugin calls to Bootstrap 5, translates legacy options and
methods, and mirrors legacy data attributes into `data-bs-*`. It does not ship
the Bootstrap 3 JavaScript runtime or directly write classes, styles, or geometry.
Bootstrap 5 owns component rendering and state changes.

Reference: `UXUI-264-update-bootstrap-from-3-4-1-to-5-3-8`, commit
`f740a026c6`, `app/bundles/CoreBundle/Assets/js/1.bootstrap-compatibility.js`.
The reference also mirrors attributes and forwards plugin methods to native
Bootstrap constructors.

## Limits of this evidence

Passing these checks is not proof of all Bootstrap 3 behavior. Constructor
presence and static attribute mappings are not behavioral equivalence tests.
Legacy APIs removed from Bootstrap 5 need explicit decisions where pure routing
has no equivalent, including modal remote loading and button loading/reset text.
Legacy custom tooltip templates and viewport semantics also require further
contract verification. The router currently drops modal `remote`; this must not
be described as complete compatibility.

The frozen baseline and supporting materials remain preserved.
